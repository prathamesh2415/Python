# Free tools snapshot (November 2026)

Re-check vendor pages before relying on credits — free tiers change often.

## Video generation (free recurring)

| Tool | Free allowance (reported) | Notes |
|---|---|---|
| Google Flow | ~50 credits/day | Strong default. Peak blocks ~14:00–17:00 UTC. Invisible SynthID. |
| Dreamina | ~120 credits/day | Good backup / Seedance motion |
| Google Vids | 3× ~15s videos/month | Longer but rare |
| PixVerse | Daily credits | Often watermarked; commercial use restricted on free |
| Local Wan 2.2 | Unlimited if you have a GPU | Truly free, technical setup |

## Usually not free anymore (don’t plan around these)

Sora (shut down), Luma free, Pika free credits, many Kling daily credits, Gemini-app video without paid plan, Runway free video in recent tests.

## Practical daily budget for 1 reel

1. Script in ChatGPT/Gemini  
2. 5–7 stills  
3. Animate 3–5 key shots in Flow  
4. Ken Burns the rest in CapCut  
5. Trending audio + export  

If Flow is empty: stills-only reel. Strong story still wins.
