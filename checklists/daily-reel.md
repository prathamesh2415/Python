# Daily reel checklist (~45–60 min)

Date: __________  
Story working title: __________

## 1. Select (≤10 min)

- [ ] Generated / reviewed 5+ candidates
- [ ] Picked 1 that is shareable / saveable / emotional
- [ ] Verified key facts (or marked as legend)
- [ ] Wrote one-sentence reason this can go viral

## 2. Script (≤12 min)

- [ ] Hook under 12 words
- [ ] Full beat sheet: hook → setup → turn → payoff → CTA
- [ ] On-screen cards: 6–10, each 4–8 words
- [ ] Read aloud once; cut anything boring

## 3. Visuals (≤20 min)

- [ ] Scene list done (`prompts/03-scene-breakdown.md`)
- [ ] Generated stills with locked style
- [ ] Animated priority scenes in Flow/Dreamina **or** Ken Burns fallback
- [ ] Files named `01`, `02`, `03`… in order

## 4. Edit (≤15 min)

- [ ] CapCut/Edits timeline assembled
- [ ] No Pro/watermarked assets
- [ ] Text readable on phone
- [ ] Trending / fitting audio added
- [ ] Export 1080×1920

## 5. Publish (≤5 min)

- [ ] Caption + hashtags ready
- [ ] Cover frame chosen
- [ ] Posted as Reel
- [ ] Logged to tracking sheet
- [ ] Replied to first 10 comments within a few hours (when possible)

## Post-mortem (next day)

- [ ] Views 24h: _____
- [ ] Shares: _____
- [ ] Saves: _____
- [ ] Keep / tweak / kill this format?
