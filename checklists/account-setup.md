# Account setup checklist (free)

## Instagram

- [ ] Create account with niche-matching username
- [ ] Switch to Creator or Business
- [ ] Profile image: symbol / stamp / illustration (not your face)
- [ ] Name field: clear niche phrase (not only username)
- [ ] Bio: what stories + for whom + soft CTA
- [ ] Link: optional (later: YouTube / own PDF / email)
- [ ] Category set correctly
- [ ] Connect Facebook Page if you may want professional dashboard later

## Content system

- [ ] Niche one-liner written
- [ ] Visual style lock written (1 sentence)
- [ ] Folder on phone/laptop: `Reels/YYYY-MM-DD-title/`
- [ ] Tracking sheet created (views / shares / saves)
- [ ] ChatGPT or Gemini free account ready
- [ ] Google Flow account ready (and/or Dreamina)
- [ ] CapCut installed; confirm free export works without Pro assets
- [ ] Save 10 story one-liners before first edit day

## First week rules

- [ ] Post at least 5 story reels before redesigning branding
- [ ] Do not buy followers / engagement
- [ ] Do not use copyrighted movie clips
- [ ] Review shares + saves every 48 hours
