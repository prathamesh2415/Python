# Prompt — Instagram caption + hashtags

```text
Write an Instagram Reel caption for this faceless story page.

Niche: [NICHE]
Story summary: [2–3 lines]
Hook already used on-screen: [HOOK]
Language: [English / Hindi / Hinglish]

Give me:
1) Primary caption
   - Line 1 = scroll-stopping hook (not emoji spam)
   - 3–6 short lines max
   - Soft CTA to follow for Part 2 / more stories
2) 2 alternate first lines for testing
3) 5–8 niche hashtags (no mega-spam tags)
4) A one-line comment I can pin that boosts replies
5) A Story sticker question tied to the reel

Tone: human, direct, curious. No “link in bio” spam. No fake urgency.
```
