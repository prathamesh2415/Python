# Prompt — Expand story into a reel script

```text
Turn this story into a faceless Instagram Reel script.

STORY:
[PASTE SUMMARY + SOURCES]

Constraints:
- Length: 20–40 seconds when read aloud at a natural pace
- Format: vertical Reels, big on-screen text, no face on camera
- Tone: [cinematic / mysterious / emotional / documentary]
- Language: [English / Hindi / Hinglish]

Output exactly these sections:

1) HOOK (max 12 words) — must create an open loop in under 2 seconds
2) FULL VOICEOVER SCRIPT (if using voice) with [PAUSE] markers
3) ON-SCREEN TEXT CARDS — 6 to 10 cards, each 4–8 words
4) BEAT TIMING — approximate seconds for hook / setup / turn / payoff / CTA
5) EMOTIONAL TARGET — what the viewer should feel at the end
6) CTA — one soft follow CTA, not spammy
7) ALTERNATE HOOKS — 3 more hooks to A/B test

Rules:
- Front-load curiosity. Do not start with “Once upon a time”.
- One clear twist or payoff. No rambling.
- Keep names/dates only if they help the story.
- If a fact is uncertain, phrase carefully or cut it.
```
