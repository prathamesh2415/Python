# Prompt — Scene breakdown + image prompts

```text
Convert this reel script into production-ready scenes for AI images + short AI video clips.

SCRIPT / TEXT CARDS:
[PASTE]

Visual style lock (use in EVERY image prompt):
"[YOUR STYLE — e.g. cinematic documentary still, muted earth tones, film grain, dramatic side light, no text in image, no watermarks, no logos]"

Aspect: 9:16 vertical composition (or square that crops cleanly to 9:16)

For each scene output:
- scene_number
- duration_seconds (4–8)
- on_screen_text
- image_prompt (detailed, style lock included)
- motion_prompt (for image-to-video: slow push-in / pan / wind / dust / rain — keep subtle)
- negative_prompt (blurry, extra fingers, modern logos, readable text, watermark, celebrity lookalike)

Also provide:
1) A consistent character/object description block if the same subject repeats
2) A CapCut edit note: cut points and where text should punch in
3) Cover-frame recommendation (which scene + which text)

Keep total animated clips to 5–7 so a free daily credit budget can finish one reel.
```
